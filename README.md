One line, a year-3000 museum label for a group chat: a sacred scroll of forty-seven priests who chanted here daily, mostly in frog images and good morning.

## Run it

```sh
node main.ts
```

The program writes the label to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
